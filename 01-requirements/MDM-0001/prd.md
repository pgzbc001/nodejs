# 需求描述

建设企业级主数据治理平台，解决"一物多码、数据标准不统一、数据质量难保障、变更管控缺失、系统间协同困难"五大痛点。平台包含两大功能模块：**主数据模型定义**（分类体系、模型创建与管理、模型详情配置、编码规则）与**主数据维护**（数据浏览查询、新增/修改/禁用删除、版本管理、导入导出、推送协同、AI查重、质量校验、操作日志）。系统由后端服务（mdm-backend）与前端应用（mdm-frontend）组成，服务五类用户角色：数据管理员、数据录入员、数据审核员、系统管理员、下游系统用户。

## 核心场景及产品逻辑定义

### 用户故事#1：分类体系管理

【前提条件】
用户以"数据管理员"或"系统管理员"角色登录平台。

【验收标准】
1. 以树形结构展示分类体系，支持无限层级
2. 支持新增同级分类和子级分类
3. 支持修改和删除分类
4. 删除时若分类下存在子分类或已关联的数据模型，系统拒绝删除并提示原因
5. 支持关键字搜索定位分类，支持一键展开/折叠全部

### 用户故事#2：数据模型创建与管理

【前提条件】
分类体系已建立，用户为"数据管理员"。

【验收标准】
1. 左侧展示分类树，右侧展示该分类下的模型列表（名称、编码、所属分类、状态、数据条数）
2. 支持空白创建与继承创建（复制已有模型结构）
3. 模型标准编码全局唯一
4. 模型上线后方可用于数据录入；上线后结构锁定，仅允许新增字段
5. 支持查看版本历史（版本号、操作人、时间、上线/下线状态）、版本回滚与版本差异对比

### 用户故事#3：模型详情配置（字段/扩展/编码规则）

【前提条件】
模型已创建且未上线。

【验收标准】
1. 基础信息：标准编码（唯一）、标准名称、所属分类、归口部门
2. 字段配置：字段名称、显示名称、数据类型（文本/长文本/数字/日期）、必填、唯一、列表展示、下拉选项、值域来源（手动固定值/引用其他模型）、多选、检索条件、弹窗选择、加密、数据分级（绝密/机密/秘密/敏感/公开）、安全规则、默认值、字段分组、自定义校验
3. 引用关系：字段可引用其他模型数据作为值域，支持引用过滤条件与级联
4. 扩展配置：流程展示标题字段、树形结构（上级节点/子级节点/展示字段）
5. 编码规则：固定值/对象引用/顺序值/编码引用四段式组合；"编码引用"仅允许出现在第一段；顺序值自动递增；按补位符与方向补足位数；编码全局唯一

### 用户故事#4：主数据浏览与查询

【前提条件】
存在已上线模型，用户为"数据录入员"。

【验收标准】
1. 左侧"分类→模型"树形导航，右侧展示选中模型的数据列表
2. 列表列根据模型字段定义（是否在列表展示）动态生成
3. 支持按模型配置的检索条件字段进行筛选
4. 支持导出 Excel；展示数据状态（有效/停用/草稿）

### 用户故事#5：新增主数据（动态表单 + 编码生成）

【前提条件】
模型已上线，用户为"数据录入员"。

【验收标准】
1. 点击新增打开侧滑表单，按模型字段定义动态渲染，按字段分组分区
2. 文本→输入框；数字→数字输入框；日期→日期选择器；选项→下拉（支持多选）；引用→弹窗选择或下拉引用
3. 必填校验、自定义校验不通过时阻止提交并提示
4. 编码按模型编码规则自动生成，用户无需输入
5. 提交时执行 AI 查重：与已有数据比对名称/规格/型号等关键字段，展示相似物料列表与相似度百分比；用户可选"使用已有物料"或"确认是新物料，继续提交"
6. 提交前执行数据质量校验，按严重/告警/提示三级展示；严重级必须修正，告警/提示可忽略继续

### 用户故事#6：修改主数据

【前提条件】
用户勾选一条有效数据。

【验收标准】
1. 打开侧滑表单并回填已有数据（加密字段脱敏回显）
2. 修改提交后自动重新执行质量校验
3. 每次修改自动生成新版本，保留历史快照
4. 关键字段修改标记协同确认需求（数据审核员确认后方可推送）

### 用户故事#7：禁用/删除主数据

【前提条件】
用户勾选数据后点击"禁用"或"删除"。

【验收标准】
1. 系统自动检查下游系统（ERP/MES/WMS 等）是否允许该操作
2. 逐行展示各系统校验状态（通过/失败/校验中）
3. 全部通过后允许执行；支持"忽略影响，强制操作"
4. 禁用后数据状态置为"停用"，删除为逻辑删除

### 用户故事#8：版本管理与差异对比

【前提条件】
该数据存在多个历史版本。

【验收标准】
1. 展示版本列表（版本号、操作类型、操作人、操作时间）
2. 支持任选两个版本逐字段差异对比
3. 支持回滚到指定版本（生成新版本承载回滚数据）
4. 支持查看任意版本详情

### 用户故事#9：数据导入导出

【前提条件】
模型已上线，用户为"数据录入员"。

【验收标准】
1. 导出当前模型数据为 Excel，支持按筛选条件导出
2. 提供标准导入模板下载（字段名称 + 格式说明）
3. 批量导入 Excel 数据，导入执行必填/格式/质量校验
4. 失败数据可下载错误明细 Excel，修正后重新导入

### 用户故事#10：数据推送与协同确认

【前提条件】
数据已创建或变更，用户为"数据录入员"或"数据审核员"。

【验收标准】
1. 选择数据手动触发推送至指定下游系统
2. 系统自动判断是否需要协同确认；需要时选择协同人并发送通知，协同人确认后自动推送
3. 推送日志记录目标系统、时间、结果
4. 推送前自动执行下游依赖校验

### 用户故事#11：操作日志审计

【前提条件】
平台已产生业务操作。

【验收标准】
1. 记录每条数据的全部操作（新增/修改/禁用/删除/推送/协同等）
2. 展示操作类型、操作人、操作时间、操作详情
3. 支持按时间范围与操作类型筛选

## 非功能性需求

| 需求 | 验收标准 |
|------|---------|
| 数据版本控制 | 所有主数据修改保留完整历史版本，支持任意版本回滚 |
| 操作审计 | 所有操作记录日志，支持追溯 |
| 编码唯一性 | 自动生成的编码全局唯一 |
| 动态表单 | 系统支持动态字段定义，灵活适配不同业务模型 |
| 数据安全 | 支持字段级加密存储、数据分级管控 |
| 批量处理 | 支持大数据量批量导入导出 |
| 响应性能 | 列表查询 < 3 秒，表单提交 < 2 秒 |
| 同步时效 | 主数据变更推送日志记录完整（实际对接在 v2.0 通过适配器扩展） |
